ADHD and task initiation: how to make the first step smaller

When a task feels hard to start, try naming one thing you could do next. “Sort out the paperwork” leaves a lot to decide. “Put one unopened letter on the desk” gives you something specific to try. A smaller step can help, and it can still feel hard.

Leicestershire Partnership NHS Trust describes difficulty starting tasks as a common experience with ADHD and suggests breaking larger tasks into smaller ones. CHADD’s ADHD Weekly suggests making the step smaller again if it still feels too daunting. NHS Trust strategies and support · CHADD’s guide to planning and procrastination

Three ways to make a first step smaller

  1. Write a report. Start with the introduction. If that still feels too big, open the draft and write one rough sentence about what the report needs to explain. You can stop once it’s saved.
  2. Deal with a stack of mail. Start with the unopened envelopes. If sorting them all feels like too much, open one envelope and write down the due date if there is one. Leave the rest for later.
  3. Catch up on messages. Pick one person to reply to. If a full reply feels like too much, open the conversation and save one sentence as a draft. You can decide later whether to edit or send it.

Decide what counts as a start

Choose a small result you can see, such as a saved sentence or a date written down. If you’re still stuck, you could try a smaller step or come back to it later. To connect that first step to the bigger task, see the guide to breaking down goals.
