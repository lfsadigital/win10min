Set up a focus timer on your Mac

Win10min for Mac is a native focus timer for Apple Silicon Macs. Use it on its own, or add the optional local ChatGPT connection to turn a goal into a plan you can review. Completed sessions add to the Roman city saved on this Mac.

Install Win10min for Mac

  1. Check compatibility. The current Mac beta requires an Apple Silicon Mac (M1 or newer) and macOS 26 or later. It does not support Intel Macs or Windows.
  2. Get the published download. Open the Win10min homepage and use its Mac download. Unzip the package.
  3. Install the application. Drag Win10min Preview.app into Applications, then open it there. The published download is signed and notarized. A copy kept inside a development folder can be harder for another tool to locate.
  4. Choose a small task. Set a clear stopping point, start a session and review the work when the timer ends. The timer measures focus time; it does not certify that a task is finished.

Choosing a Pomodoro timer for Mac or a shorter focus session

A traditional Pomodoro routine alternates 25 minutes of work with a short break. If starting feels difficult, a ten-minute session gives you a smaller first commitment. Choose the duration around a concrete task: outline three points, review five notes or draft one paragraph.

Win10min is a focus timer with Roman progress rewards. Choose one task, set a clear stopping point and review what you completed when the session ends. For a shorter routine, follow the ten-minute focus guide.

App hiding and app blocking are different

Win10min for Mac can hide selected app windows to reduce visible distractions. You can reopen those apps. It does not lock applications or block websites. The iPhone app uses a separate Apple Screen Time blocking system.

If you need a Mac website blocker, this beta does not provide that feature. Keep the tools required for your task available and choose distraction controls that match your needs.

Use ChatGPT planning when you want it

  1. In the Mac app’s GPT page, select Install connection.
  2. Start a new local Work or Codex chat in a compatible desktop host with local-plugin access, then select the Win10min connection.
  3. Describe your goal, available time and the result you want. Review the proposed steps.
  4. Ask the assistant to send the plan to Win10min when you want to use the app. Open the app, review the queue and start the session yourself.

The local connection is separate from the public ChatGPT directory. The current published connection does not work in ChatGPT web or mobile. Planning uses your chat account’s allowance and applicable credits; the Mac timer does not require ChatGPT.

If the assistant cannot open the app

The application is named Win10min Preview. Open Finder → Applications → Win10min Preview.app yourself. Keep the app installed in Applications, and start a fresh chat after updating the connection so that the latest instructions can load.

For a command-line shortcut, open -b com.win10min.mac.preview uses its stable application identifier. An unfinished saved plan must be finished or dismissed before another plan replaces it; the assistant should not dismiss your work without agreement.

Where your progress lives

The Mac beta stores its progress and settings on this Mac. It does not sync progress, purchases or settings with iPhone. Mac Arena, the iPhone campaign features and full iPhone analytics are not included in this beta.
