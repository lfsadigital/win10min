A few things to know.

How do I install the Mac beta?

Unzip the download. Drag Win10min Preview to Applications, then open it. Choose a task and the apps you want hidden, and start your session.

Version 0.16.2 · Apple Silicon · macOS 26 or later. Release details.

Do I need ChatGPT?

No. The Mac timer and saved progress work without it. Optional ChatGPT planning breaks goals into manageable actions. Send a plan to Win10min, then start it yourself.

In Win10min’s GPT page, select Install connection. Choose Win10min for Mac in a new local Work/Codex chat. Requires a compatible desktop host with local-plugin access; ChatGPT web and mobile are not supported. Uses your account’s allowance and applicable credits.

What’s missing from the Mac beta?

Website blocking, iPhone-style Screen Time shields, Arena and full iPhone analytics. Intel Macs and Windows aren’t supported. Progress, settings and purchases are separate from iPhone.
